Privacy Policy

Last updated: 12 November 2026

Version 1.0

1. Who is responsible

Fresh Deps is made by RNGenesis, an individual developer in Saudi Arabia. Contact: rngenesisdev@gmail.com.

2. The short version

  • RNGenesis runs no server for this plugin and receives no data from it.
  • There is no telemetry, analytics, crash reporting or advertising.
  • To show versions, the plugin asks package registries about the packages named in your build files. Those requests go straight from your computer to the registry.

3. What the plugin sends, and where

Every request is a GET made by your IDE, through the IDE's proxy settings. Requests to the public hosts below use HTTPS. A private registry is asked at the address your own config gives, which can be http. Each host therefore sees your IP address, the package name in the URL, and the User-Agent FreshDeps (JetBrains IDE plugin). The IDE adds its own standard headers. Registries can redirect to their own download hosts, and the plugin follows those redirects.

Host When What is sent Credentials sent
registry.npmjs.org (npm) When a package.json file is open or scanned. The package name, to find the latest version. For an update, the package document. For release notes (Pro), also the newest version number. None for Free users. With Pro, the login your own .npmrc holds for that registry, if any.
pypi.org (PyPI) When a pyproject.toml file is open or scanned. The project name, to find the latest version. For an update, the project's JSON data. For release notes (Pro), the project name and newest version. Never. PyPI never receives a login.
crates.io When a Cargo.toml file is open or scanned. The crate name. No more than one request per second. Never. The crates.io token is never sent.
repo.maven.apache.org (Maven Central) When a pom.xml, build.gradle, build.gradle.kts or Gradle version catalog is open or scanned. The group and artifact, as a path, to read the list of versions. For release notes (Pro), the newest version's pom file. None, unless your settings.xml or gradle.properties holds a login for a repository at that address and you have Pro.
dl.google.com (Google's Maven repository) The same as Maven Central. Asked first for Android and Google mobile groups and plugin ids (androidx, android, com.android, com.google.android, com.google.firebase, com.google.gms, com.google.mlkit, com.google.ar), then Maven Central or the Gradle plugin portal. The group and artifact, or the Gradle plugin id, as a path. The same as Maven Central.
plugins.gradle.org (Gradle plugin portal) When a build.gradle, build.gradle.kts or Gradle version catalog that names a plugin is open or scanned. The Gradle plugin id, as a path. The same as Maven Central.
api.github.com Only when you open a release-notes card (Pro). The owner and name of the dependency's public repository, to read its releases, up to two pages. A cache header is also sent. Your GitHub token, only if you saved one in Settings > Tools > Fresh Deps or set GITHUB_TOKEN. It is sent only to api.github.com, never to another host after a redirect. Without a token the request is anonymous.
Other addresses of the same public registries, only if your own config names them: registry.yarnpkg.com, pypi.python.org, repo1.maven.org, maven.google.com The same as the registry each one stands for. The same as the registry each one stands for. None for Free users.
Private registries you configured (Pro only) Any other host named in your own files. The package name, and for npm and Maven release notes the newest version. The login your files hold for that host. Without a Pro licence these hosts are never contacted and no login is sent anywhere.

Scanned means read by the Fresh Deps tool window, which reads every build file in the project once you open it. Answers are reused for 1 hour.

JetBrains: the plugin itself makes no request to JetBrains. Your IDE obtains and checks licences with JetBrains. The plugin only reads the licence stamp the IDE holds and checks its signature offline, against JetBrains' public certificates built into the plugin.

The version you currently use is never sent. Where a version appears in a request, it is the newest published version, used to find release notes.

No other file contents, project name, file path, user name or machine identifier are sent by the plugin itself.

Clicking a link in a release-notes card opens your web browser at that address. The plugin does not load images or other remote content inside the card.

4. Credentials the plugin reads on your computer

The plugin reads these files for every user, on your computer, to learn which registry a package belongs to. A login from them is sent only with a Pro licence, and only to the registry it belongs to.

  • npm: ~/.npmrc, or the file named by the npm_config_userconfig variable, and the project's .npmrc. Tokens, _auth values and user and password pairs become the login for the matching registry address only. ${VAR} in .npmrc is replaced from your environment, as npm does.
  • Maven: server logins in ~/.m2/settings.xml.
  • Gradle: gradle.properties in GRADLE_USER_HOME or ~/.gradle, for repositories declared with password credentials.
  • Python: uv.toml (user and system), pip.conf or pip.ini, .netrc or _netrc (or the file named by NETRC), and the environment variables UV_INDEX_<NAME>_USERNAME and _PASSWORD, POETRY_HTTP_BASIC_<NAME>_USERNAME and _PASSWORD, PIP_INDEX_URL, PIP_EXTRA_INDEX_URL, UV_INDEX, UV_EXTRA_INDEX_URL, UV_DEFAULT_INDEX and UV_INDEX_URL. A login written inside an index address (user:password@host) is read too. The system keyring is never read.
  • Cargo: the config and credentials files in CARGO_HOME or ~/.cargo, the .cargo config files of a project you marked as trusted, and the CARGO_REGISTRIES_<NAME>_TOKEN variable. A token stays with its own index.
  • GitHub token: an entry in the IDE's password store whose name contains "Fresh Deps" and "GitHub token", or else the GITHUB_TOKEN variable.

Safeguards:

  • A credential is chosen again for every redirect, and is never sent after a change from https to http.
  • A project's own config files (.npmrc, Maven repositories, Gradle scripts, Cargo config and Poetry sources) decide where requests go only after you mark the project as trusted in the IDE.
  • Credentials and the text of these files are kept in memory only while the IDE runs. The plugin does not write your credentials to disk. The one exception is a GitHub token you type in, which is saved to the IDE's password store.

5. What is stored on your computer

  • Ignored version lines ("Ignore 19.x"): the registry, package name and version line, stored in the project's .idea/workspace.xml. Remove them in Settings > Tools > Fresh Deps.
  • GitHub token, if you enter one: stored in the IDE's password store, which is your OS keychain or the IDE's KeePass file, depending on how your IDE is set up. Remove it with the remove button on the same settings page. The settings page never shows the saved token.
  • Caches: registry answers are kept for 1 hour, failed lookups for 5 minutes, and GitHub release lists for 1 hour. They are kept in memory and cleared when the IDE closes. They are not written to disk.
  • IDE log: when a lookup or a release-notes request fails, the plugin writes the package name, the registry address and the error into your IDE's own log file. The plugin removes logins from the addresses it logs. The error text comes from the IDE and can include the full request address. The log stays on your computer unless you send it to someone.
  • No other settings are stored.

7. Purchases and licences

Pro licences are sold through JetBrains Marketplace. JetBrains processes the order, payment, invoices and refund requests, and holds your account and payment data under its own privacy notice: JetBrains Privacy Notice.

RNGenesis does not receive your payment card details.

JetBrains may share limited order and licence information with RNGenesis for accounting and support. RNGenesis uses it only for those purposes.

9. Your choices and how to object

  • To stop all network requests from the plugin, disable or uninstall it. You can also switch each kind of hint off in Settings > Editor > Inlay Hints and keep the Fresh Deps tool window closed.
  • To send no token to GitHub, do not save one in the settings, and do not set the GITHUB_TOKEN variable.
  • Requests to private registries happen only with a Pro licence. Config files in projects you have not marked as trusted are ignored.
  • For questions, access, deletion or objection about support email, write to rngenesisdev@gmail.com.
  • You can ask what we hold about you, and ask us to correct or delete it.

We answer privacy requests within 30 days.

10. Children and changes
