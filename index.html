Fresh Deps

A JetBrains IDE plugin that shows the newest version next to each dependency in your build files and updates them for you.

Fresh Deps works in package.json, Gradle version catalogs (libs.versions.toml), build.gradle, build.gradle.kts, pom.xml, pyproject.toml and Cargo.toml.

Each dependency that names one version gets a small hint. The hint shows the newest version from npm, Maven Central, Google's Maven repository, the Gradle plugin portal, PyPI or crates.io.

The hint uses these marks:

  • ↑ a newer patch release
  • ⇑ a newer minor release
  • ⚠ a newer major release
  • ✓ already the latest version

Click a hint to update that dependency. Free updates go to the newest patch of your own line (18.3.1 to 18.3.2); Pro adds minor and major updates. The Fresh Deps tool window lists every outdated dependency in the project.

Requires JetBrains IDE 2025.1 or newer.

Free and Pro

Free Pro
  • Version hints for public registries.
  • Update one dependency to the newest patch of its line.
  • Update every patch in a file at once.
  • A tool window that lists outdated dependencies.
  • Minor and major updates from the hint or the tool window. Tick several and update them together.
  • Update every patch in the whole project at once.
  • Release notes for an update, from GitHub Releases, when the package's registry links a GitHub repository.
  • Packages from private registries, read from your .npmrc, Maven settings.xml, Gradle, Python and Cargo settings, with the logins saved in those tools' config files (not keyrings or encrypted passwords).

Without a licence, Pro actions are greyed and marked Pro, and packages from a private registry are never looked up. A Maven or Gradle file that also uses a private repository gets hints only with Pro.
