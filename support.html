Support

Last updated: 12 November 2026

Contact

Email is the only support channel: rngenesisdev@gmail.com.

Response times

We reply within 5 business days. Issues JetBrains marks as critical get a reply within 2 business days.

A reply is a response, not a guaranteed fix.

Support hours are Sunday to Thursday, 09:00 to 17:00 Arabia Standard Time (UTC+3).

How to report a bug

Send these details by email:

  1. The plugin version (Settings > Plugins > Fresh Deps) and the IDE name and build (Help > About).
  2. Your operating system.
  3. The build file type (package.json, pom.xml and so on) and the smallest dependency line that shows the problem.
  4. What you expected and what you saw. A screenshot of the hint helps.
  5. Whether a private registry or proxy is involved. Name the kind of server (for example Artifactory), but not its address if it is private.
  6. Relevant lines from the IDE log (Help > Show Log) that mention "Fresh Deps" or "deplens".

Never send passwords, tokens, .npmrc, settings.xml, gradle.properties, .netrc or Cargo credentials.

Remove private package names and internal host names from logs before sending. The log can hold package names and registry addresses.
